# Default master prompt

The editable default is written in English. Vietnamese recipe fields must use full diacritics; the English fields remain available for the English interface.

```text
Plan a practical, varied weekly family menu with easily available ingredients. Follow the selected household size, days, meal times, dietary restrictions, allergies, cooking appliances, time limit, budget, pantry and custom request. Treat the Additional request as explicit instructions before the defaults below: honor the requested meal count, cuisine, ingredients, cooking method and any named day or meal as ONE weekly request, never once per batch or per alternative. The selected schedule, servings, dietary exclusions, appliances and time limit remain hard limits. Apply the following preferences across the ENTIRE week, including meals already planned in other meal-time batches.

1. Savory main dishes: Prefer each distinct savory main dish only once per week. Repeat a dish only when the household constraints make it necessary, and never more than twice in the week. Renaming or translating a dish does not make it a different dish.

2. Main-ingredient variety: Track the actual primary ingredient and fish species, rather than just the recipe title. If basa has already been used, prefer salmon, pompano, cobia, mackerel, tuna or another suitable available fish for later fish meals. Choose alternatives that fit the budget, pantry, dietary restrictions and available equipment.

3. A new cooking method is not a new ingredient: Braised basa and fried basa still use the SAME fish species and count as repeated use of basa when checking ingredient variety. Apply the same reasoning to other primary ingredients. Count substantial main-dish proteins; shared seasonings such as fish sauce and small soup garnishes are not the main protein.

4. Rotate food groups: Alternate pork, beef, chicken, fish, shrimp, squid, eggs and other suitable proteins to avoid monotonous consecutive meals. Adapt this rotation to the selected diet and excluded ingredients; never introduce a prohibited food to satisfy variety.

5. Cuisine: Prefer Central Vietnamese home cooking with rich, savory, appetizing flavors. Mix in occasional simple meals such as spaghetti or fried rice. Adapt seasoning to the household and honor an explicitly selected cuisine when it differs from this default preference.

6. Shopping and preparation: Reuse vegetables, aromatics and seasonings to reduce waste and combine compatible advance-preparation tasks, while limiting repeated savory mains. Include a main dish and a simple side or soup where appropriate, exact quantities for the selected servings, separate advance-preparation and cooking steps, realistic timings and suitable storage/thawing guidance. Reusing ingredients must not become an excuse to repeat the same main dishes.

7. Vietnamese language: ALWAYS write natural Vietnamese with full, correct diacritics in every Vietnamese field, including the plan title, dish names, ingredients, categories, preparation instructions, cooking instructions and storage/thawing guidance. Never use unaccented Vietnamese or transliterated spellings. Also supply the corresponding English fields required by the application's bilingual format. Preserve all numeric amounts, units and bracketed quantity tokens exactly between the two languages.

Before returning a batch, compare it with the meals already planned for this week and check dish repetition, fish-species variety and protein-group rotation. Use the bundled default recipe as a reference for structure and useful detail, not as a list of dishes to copy.
```
